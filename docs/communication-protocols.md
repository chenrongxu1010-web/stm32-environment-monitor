# 通信、引脚与模块接口

以下参数由 `.ioc`、main.c、MSP 和器件驱动核对。

| 外设 | 接线 / 配置 |
| --- | --- |
| AHT20 | I2C1 PB8 SCL / PB9 SDA；7-bit 0x38，HAL 参数左移一位；100 kHz |
| SSD1306 | 与 AHT20 共用 I2C1；7-bit 0x3C |
| W25Q64 | SPI1 PA5 SCK / PA6 MISO / PA7 MOSI，PB6 软件 CS |
| SPI 配置 | Master、8-bit、MSB first、CPOL=0、CPHA=1 Edge、64 分频；默认业务不初始化 SPI |
| UART | USART2 PA2 TX / PA3 RX，经 ST-LINK VCP；115200 / 8N1，无流控 |
| 蜂鸣器 | PB5，低电平触发；电源按实际模块额定值连接 |
| B1 | PC13，下降沿 EXTI，50 ms 间隔过滤 |
| 电源 | 逻辑接口 3.3 V，共地；按器件规格确认模块电源 |

AHT20 发送 `AC 33 00`、等待 80 ms、读取 6 字节并检查 Busy 位，拼接两个 20-bit 值；当前没有 CRC 校验和总线重初始化策略。OLED 驱动封装命令、页清除与字符显示，显示任务在初始化成功后使用；负温度显示格式仍需补测。

W25Q64：`9F` JEDEC ID，`05/35/15` 状态寄存器，`06` 写使能并检查 WEL，`20` 扇区擦除，`02` 页编程，`03` 数据读取。单次页编程不超过 256 字节且拒绝跨页；BUSY 等待上限 5000 ms，底层 SPI 调用超时 100 ms。尚未完整验证地址容量边界与掉电原子性。

Config 在 `0x002000` 保存四个 uint16_t 阈值（×10）；默认温度 300/290，湿度 900/850，检查恢复值小于触发值、触发值不超过 1000。无版本、CRC 或双副本。默认 RAM 配置路径使用这些默认阈值；启用 Flash 后，非法数据回退默认值，当前代码未自动写回。

Alarm 正常态任一值达到触发阈值即报警（OR），报警态两项均小于等于恢复阈值才恢复（AND）。禁用报警改变蜂鸣器使能，不等同于清空内部报警状态。
