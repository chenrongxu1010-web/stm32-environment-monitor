| I2C 超时 | 在安全断电接线后模拟传感器不应答，再上电；记录调用结果、锁等待、其他任务状态 | HAL 错误按有限超时返回且 Mutex 释放，系统不死锁；当前无重初始化策略，恢复不成功如实记录，不宣称自动恢复 |
| Mutex 竞争 | 测试配置下增加显示频率，记录两任务获取/释放时刻，并抓取 I2C 波形 | 不出现两任务事务交叉；记录最大等待与持锁时间，不能仅用画面正常判断互斥有效 |

## 执行前需补充的监测

现有正常 UART 仅输出温湿度与报警状态；8 小时方案需要添加统一遥测、心跳、错误计数、复位原因与 heap 指标。当前栈更新依赖传感器成功数据，失联时应由独立监测路径采样。上述遥测和故障注入增强尚未实现，不能直接把计划作为可执行测试脚本。

Flash 擦写和掉电测试独立执行：备份并限定可覆盖扇区，分别验证擦除态、页边界、写后读回和真正断电读回；保留异常首帧和失败样本。
